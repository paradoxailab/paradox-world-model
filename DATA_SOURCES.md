# Data sources

No data is stored in this repository. Each script downloads the public source data itself.

| Dataset | What it is | Source | How the code gets it | Terms |
|---|---|---|---|---|
| PEMS08 | 17,856 five-minute steps × 170 highway sensors, San Bernardino (Caltrans District 8), Jul–Aug 2016; 270 road links with distances | Caltrans Performance Measurement System (PeMS), benchmark copy distributed with ASTGNN | `curl` from `https://raw.githubusercontent.com/guoshnBJTU/ASTGNN/main/data/PEMS08/` (`PEMS08.npz`, `PEMS08.csv`) | Caltrans public data; research benchmark copy |
| PEMS04 | 16,992 five-minute steps × 307 sensors, San Francisco Bay Area (District 4), Jan–Feb 2018 | as above | `.../data/PEMS04/` (`PEMS04.npz`, `PEMS04.csv`) | as above |
| IMD rainfall, central India | India Meteorological Department 0.25° gridded daily rainfall, 2000–2024, 21–26.75° N, 74–82.75° E (Madhya Pradesh and surroundings); land cells with > 90 % coverage | IMD Pune gridded data | `pwm.data.download_imd("central_india", 2000, 2024)` using the `imdlib` package (Nandi, Patel & Swain 2024) | IMD data terms; cite IMD and imdlib |
| IMD rainfall, Konkan / Western Ghats | same product, 14–20.75° N, 72.5–76.25° E | IMD Pune gridded data | `download_imd("west_coast", 2000, 2024)` | as above |
| Synthetic rainfall (tests only) | 8×8 fake grid, 2015–2024, used only to check the pipeline offline | generated by `tests/make_synthetic_imd.py` | included (`data/raw/SYNTHETIC_IMD_rain_test.npz`) | never reported; the report generators refuse it |

## Splits

- PeMS: chronological 60 % train / 20 % validation / 20 % test (standard protocol).
- IMD: 2000–2018 train, 2019–2021 validation, 2022–2024 test.
- Normalisation statistics come from the training split only.
