# Data sources

No data is stored in this repository. Each script downloads the public source data itself.

| Dataset | What it is | Source | How the code gets it | Terms |
|---|---|---|---|---|
| PEMS08 | 17,856 five-minute steps × 170 highway sensors, San Bernardino (Caltrans District 8), Jul–Aug 2016; 270 road links with distances | Caltrans Performance Measurement System (PeMS), benchmark copy distributed with ASTGNN | `curl` from `https://raw.githubusercontent.com/guoshnBJTU/ASTGNN/main/data/PEMS08/` (`PEMS08.npz`, `PEMS08.csv`) | Caltrans public data; research benchmark copy |
| PEMS04 | 16,992 five-minute steps × 307 sensors, San Francisco Bay Area (District 4), Jan–Feb 2018 | as above | `.../data/PEMS04/` (`PEMS04.npz`, `PEMS04.csv`) | as above |
| IMD rainfall, central India | India Meteorological Department 0.25° gridded daily rainfall, 2000–2024, 21–26.75° N, 74–82.75° E (Madhya Pradesh and surroundings); land cells with > 90 % coverage | IMD Pune gridded data | `pwm.data.download_imd("central_india", 2000, 2024)` using the `imdlib` package (Nandi, Patel & Swain 2024) | IMD data terms; cite IMD and imdlib |
| IMD rainfall, Konkan / Western Ghats | same product, 14–20.75° N, 72.5–76.25° E | IMD Pune gridded data | `download_imd("west_coast", 2000, 2024)` | as above |
| Synthetic rainfall (tests only) | 8×8 fake grid, 2015–2024, used only to check the pipeline offline | generated by `tests/make_synthetic_imd.py` | included (`data/raw/SYNTHETIC_IMD_rain_test.npz`) | never reported; the report generators refuse it |

## Atlas (2026-11) datasets

Not stored here either: the raw data are third-party, and WEATHER-5K alone is 6.4 GB (GitHub refuses files over 100 MB).
Each script below rebuilds the exact arrays the results use; the runs' own logs (`atlas/results/kaggle/`) print the
shapes and missing shares to check a rebuild against.

| Dataset | What it is | Source | How the code gets it | Terms |
|---|---|---|---|---|
| WEATHER-5K | 5,672 weather stations worldwide, hourly 2014–2023; temperature, dew point, wind direction and speed, sea-level pressure (ICML 2026 benchmark) | the benchmark authors' public download (HKUST OneDrive share) | `atlas/delhi/tools/fetch_weather5k.py` → `W5K_X.npy` [5672, 87648, 5] float16 + `W5K_META.npz` | the WEATHER-5K authors' terms; cite their paper |
| Delhi stations | 39 CPCB continuous ambient monitoring stations, 15-minute pollutants and meteorology, 2024–25 | OpenCity "Delhi Hourly Air Quality Reports" (CPCB data) | `atlas/delhi/tools/fetch_delhi.py` → `DELHI.npz` | public domain (as published by OpenCity) |
| All-India stations | 453 CPCB / state-board stations, hourly, 2010–2023 (league uses 14 networks, 263 stations) | Kaggle dataset "Time Series Air Quality Data of India (2010-2023)", a public copy of CPCB's exports | attach to the notebook; `atlas/delhi/tools/build_india_long.py` → `INDIA_LONG.npz` | as stated on the Kaggle dataset page; cite CPCB |
| ERA5 weather | reanalysis at each station's 0.25° cell: temperature, humidity, rain, boundary-layer height, wind, pressure, cloud | Open-Meteo historical archive (ERA5 by the Copernicus Climate Change Service) | `atlas/delhi/tools/fetch_weather_india.py`, `fetch_era5_delhi.py` | data CC BY 4.0; Open-Meteo's free API is for non-commercial use |
| Day-before forecasts | the forecast issued the previous day for the same variables (archived from Jan 2024) | Open-Meteo previous-runs API (ECMWF IFS and national services) | `atlas/delhi/tools/fetch_weather_india.py` | as above |
| Operational Day-1 numbers (comparison only) | published errors of IITM WRF-Chem and IMD SILAM, Delhi winter 2024–25 | CEEW issue brief "How Well can Delhi Predict Air Quality?" (Oct 2025) | typed into `atlas/delhi/score_i1.py` | cited numbers; by number only |
| Published WEATHER-5K baselines (comparison only) | MAE of ECMWF-HRES, PhysicsFormer, DLinear and others | WEATHER-5K paper, Table 2 and per-lead tables | typed into `atlas/delhi/score_w5k.py` | cited numbers; by number only |

Commercial note: Open-Meteo's free API is licensed for non-commercial use. A commercial product built on the ERA5 or
forecast inputs needs Open-Meteo's commercial plan or direct Copernicus / ECMWF access.

## Splits

- PeMS: chronological 60 % train / 20 % validation / 20 % test (standard protocol).
- IMD: 2000–2018 train, 2019–2021 validation, 2022–2024 test.
- Normalisation statistics come from the training split only.
