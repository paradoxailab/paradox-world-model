# PWM-W paper: a small station-graph world model for 0–24 h weather in north India

Aditya Kumar and Anupam Singh, ParadoxAI Lab.

The development record of PWM-W from v0.3 to v0.9 (code on branches `delhi-v0.3` … `delhi-v0.8`), written version by
version, including the changes that failed validation and the comparisons we lose.

- `PWM-W_India_v0.3-v0.9.pdf`: named preprint build (`latexmk -pdf main.tex`)
- `PWM-W_India_anonymous.pdf`: double-blind conference build (`latexmk -pdf anon.tex`)

v0.9 (PWM-X, the data-threshold study for all three leagues, and the live track) is included; v1.0 and v2.0 are in their branches.
